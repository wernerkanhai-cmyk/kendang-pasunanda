Kendang Pasunanda — Referensi UI

Ringkasan semua elemen kontrol dalam aplikasi

Header
🎵 Menu Lagu Simpan (Update / Save as new / Save copy), lagu baru, buka pustaka, terbitkan sebagai templat (admin)
☰ Ikhtisar Komposisi SongMap: lihat baris, susun ulang, navigasi cepat ke baris tertentu
▸ Instrument Panel Instrumen DrumPad dan pengaturan suara. Klik segitiga = buka/tutup. Klik ganda bilah = buka/tutup. Seret bilah = pindahkan
A Volume Anak Seret atas/bawah untuk volume. Klik ganda = atur ulang ke 100%
I Volume Indung Seret atas/bawah untuk volume. Klik ganda = atur ulang ke 100%
◎ Mode Latihan Aktif/nonaktif. Memblokir input not. Warna emas = aktif. Playhead otomatis tergulir ke tampilan saat beralih
⋯ Menu Alat Ekspor PDF, pengaturan tata letak PDF, panduan, pilihan bahasa, akun (email, ubah kata sandi, status online/offline), keluar
⏱ Offset Sinkronisasi Kursor Penggeser untuk kompensasi penundaan Bluetooth/AirPlay. Rentang: -3000 hingga +500 ms. ↺ = atur ulang ke 0
Per Baris (Seksi)
Nama Nama Baris Klik untuk mengedit. Mengisi ruang yang tersedia hingga Manage
≡ Manage Tampilkan/sembunyikan tombol penyimpanan snippet dan manajer snippet
💾 Simpan Snippet Pilih rentang terlebih dahulu. Pilih nama dan folder (dropdown dengan folder yang ada atau buat folder baru)
▾ Place at cursor Sisipkan Snippet Dropdown untuk menyisipkan snippet tersimpan pada posisi kursor. Bisa berkali-kali berturut-turut
⚙️ Manajer Snippet Ganti nama, pindahkan, ganti nama/hapus folder, hapus massal via kotak centang, lihat templat, ekspor/impor
📋 Duplikat Buat salinan baris ini
🗑 Hapus Hapus baris ini. Dialog konfirmasi akan muncul
-1+ Birama Tambah (+) atau hapus (-) birama pada baris ini
Tempo (Per Baris)
▸ / ▾ Buka/Tutup Tempo Klik = panel ini. Klik ganda = semua panel tempo sekaligus. Saat pemutaran: baris aktif terbuka otomatis
♩ BPM Rentang Tempo Menampilkan rentang BPM baris ini. Klik ganda di area tempo = tambah titik. Seret titik = sesuaikan
ON / OFF Tempo Aktif/Nonaktif Aktifkan otomatisasi tempo per baris. Nonaktif = BPM global. Tempo terakhir diwariskan ke baris berikutnya
ALL Semua Aktif/Nonaktif Aktifkan atau nonaktifkan semua trek tempo di lagu sekaligus
+1 / −1 Penyetelan Halus Klik = +1 atau -1 BPM. Tahan = mengulang (mempercepat setelah 1 detik). Muncul di popup zoom
Bilah Transport (Mengambang)
⠿ Pegangan Seret Seret bilah transport ke posisi lain di layar
BPM ▲▼ Tempo Global Rentang 20–140 BPM. Klik angka = ketik nilai. Seret atas/bawah = sesuaikan. Panah = +1/-1
◀ Mundur Klik = awal birama saat ini. Sekali lagi = birama sebelumnya. Klik ganda = awal lagu
▶ Putar / Stop Mulai/berhenti pemutaran. Lagu berhenti otomatis di akhir kecuali ada loop yang aktif
↺ Loop Aktif/nonaktifkan loop seksi ini. Saat dinonaktifkan selagi pemutaran: iterasi saat ini diselesaikan dahulu
♩ ▾ Metronom Klik = aktif/nonaktif. Ketuk ▾ = opsi: hitungan 4 sebelum mulai, hitungan 8 sebelum mulai, klik saat pemutaran, penggeser volume
Ketuk 2x bilah Minimalkan Klik ganda pada bilah transport = minimalkan hingga hanya ◀ dan ▶. Sekali lagi = pulihkan
Trek (Anak / Indung)
● Lingkaran Bisukan Hijau = trek berbunyi (dengan cahaya). Klik = bisukan (abu-abu). Terletak di antara anak dan indung
1 2 3 4 Penggaris Birama Klik ganda = loop 1 birama. Seret beberapa birama = loop lebih lebar. Klik ganda di mana saja = hapus loop
▼ Playhead Segitiga biru. Seret untuk memindahkan kursor. Bergulir otomatis saat mundur dan beralih mode
Sel Kisi Notasi Klik = menempatkan kursor. Masukkan not via pad atau keyboard. Klik ganda pada not = hapus. Seret = pindahkan
⟳ Loop Seksi Di kanan bawah trek. Loop hanya baris ini. Klik beberapa baris = gabungkan
Lainnya
+ Regel Sisipkan Baris Muncul di antara dua baris. Menyisipkan baris kosong baru pada posisi tersebut
+ Add Section Tambah Baris Menambahkan baris kosong baru di bagian bawah lagu
● Indikator Perubahan Titik kuning di samping nama lagu = perubahan belum tersimpan. Hilang setelah Update atau simpan otomatis (5 dtk)
